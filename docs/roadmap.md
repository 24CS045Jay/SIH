# Product roadmap

The current implementation prioritizes the source-grounded document loop, authentication/RBAC, OCR reliability, workflow traceability, deployment diagnostics, and the professional portal shell.

The following advanced items remain candidates for a subsequent iteration: real-time WebSocket/SSE alert delivery, a dedicated System Administrator taxonomy editor, PDF compliance-digest export, per-user saved searches, an experimental Malayalam OCR toggle, and a real Postgres `pgvector` column/index migration once the target managed Postgres extension policy is confirmed. The current RAG path remains safe and deterministic through chunk-level access control, local embeddings, hybrid keyword/vector-like scoring, reranking, citation validation, and explicit refusal.

These items are intentionally tracked here rather than represented as fake UI or unverified production claims.
