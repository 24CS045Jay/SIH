# Student Illustration Asset

## Required File

Place your 3D animated student illustration here:

**Filename**: `student-illustration.png` (preferred) or `student-illustration.svg`

## Image Specifications

### Recommended Specs
- **Format**: PNG with transparent background (preferred)
- **Dimensions**: 800-1200px width, 1000-1500px height
- **Aspect Ratio**: Portrait orientation (character standing)
- **File Size**: < 500KB (optimize for web)

### Character Style
Based on your reference image, the ideal character should be:

- **Type**: 3D animated male student
- **Pose**: Standing, possibly pointing up or holding books/tablet
- **Outfit**: Casual (denim jacket, t-shirt, jeans) with backpack
- **Props**: Books, tablet, or study materials
- **Expression**: Friendly, enthusiastic, approachable
- **Style**: Modern 3D render similar to Pixar/Disney style

### Background
- **Transparent PNG recommended** (the gradient is handled by the page)
- If using colored background, use violet/purple tones to match the theme
